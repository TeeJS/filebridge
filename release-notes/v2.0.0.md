FileBridge is now its own Windows app. It used to run inside Bedrock Panel; it now has a normal desktop window and keeps running in the tray when you close it.

## New

- **Its own window and tray.** Close the window and your schedules keep running in the tray. Tray menu: Open FileBridge, Start with Windows, Quit.
- **Start with Windows** (tray menu, off by default) starts FileBridge hidden in the tray when you sign in.
- **Import from Bedrock Panel.** On first start, FileBridge offers to bring over your Bedrock Panel jobs with their stats, filter groups, rule files, seen-ledgers, results and log. Bedrock Panel then stops running them, and nothing in its folder is deleted.
- **Change client… for Google Drive.** You can now replace a stored Google OAuth client, for example after a Google Cloud project is deleted. Before, a dead client could not be changed.
- **Status for Bedrock Panel.** FileBridge writes `%APPDATA%\FileBridge\status.json`, which Bedrock Panel's FileBridge page reads to show live progress, next runs and last results. That page becomes read-only once you update it.

## Changed

- Jobs now live in `%APPDATA%\FileBridge\` instead of `%APPDATA%\bedrock-panel\file-bridge\`.
- The Google Drive sign-in is stored encrypted for your Windows account in `%APPDATA%\FileBridge\oauth.json`.
- FileBridge opens no network port except the Google sign-in callback on `127.0.0.1`, and only while you are connecting Drive.
- Web-drop runs clear the site's browser cache when they finish, so it no longer builds up on your C: drive. Your saved sign-in is kept.
- A Google Drive sign-in that has expired or been revoked now shows as **not connected** on the chip, instead of failing every run behind a green chip.

## After importing

- **Google Drive:** click **Change client…** on the Google Drive chip, paste your client ID and secret, and connect.
- **Web-drop sites:** sign in once per site from the **Accounts** strip.

## Install

- **Installer:** run `filebridge-setup-2.0.0.exe`. It is signed and installs for your Windows account only; no administrator rights are needed.
- **Portable:** run `filebridge-portable-2.0.0.exe` from any folder, with no install. It is signed too. It unpacks itself to a temporary folder each time it starts, so it starts a little slower. Your jobs and settings live in `%APPDATA%\FileBridge` either way, shared with the installed version (only one can run at a time).
