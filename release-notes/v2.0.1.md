FileBridge now runs on **macOS** (Apple Silicon) and **Linux** (x64) as well as Windows.

## New

- **macOS (Apple Silicon):** `FileBridge-2.0.1-arm64.dmg` and `.zip`, signed with Developer ID and notarized by Apple. It lives in the menu bar, and **Open at Login** (menu-bar menu) starts it at sign-in.
- **Linux (x64):** an AppImage and a `.deb`, with SHA256 sums in `SHA256SUMS-linux-2.0.1.txt`. **Start at login** in the tray menu adds a standard autostart entry. On a desktop with no tray (GNOME without the AppIndicator extension), closing the window minimizes FileBridge instead of hiding it.
- **Your Google Drive sign-in is stored in the system keychain:** the Keychain on macOS, and GNOME Keyring or KWallet on Linux. If no keyring is running on Linux, FileBridge refuses to connect and tells you why, rather than storing the sign-in unprotected.

## Changed

- Job folders accept the paths your system uses: `C:\…` and `\\server\share\…` on Windows, and `/…` on macOS and Linux.
- FileBridge checks whether each source and destination folder treats `Photo.jpg` and `photo.jpg` as the same file, instead of assuming it from the operating system. This matters for case-sensitive drives, network shares and USB sticks.
- On macOS and Linux, "keep read-only" copies a file's read-only state without changing its other permissions. It does not mark folders read-only there, because on those systems a read-only folder blocks the next run from adding files.

## Fixed

- **Web-drop downloads that stall** (seen on Mystery Makers). When a site stops sending a file partway through, FileBridge now asks for it again, up to twice. If it still stalls, FileBridge cancels it and tries again on the next run. Before, it waited about ten minutes and could leave a cut-off file under the real name.
- Files now download under a temporary `.part` name. They get their real name only once they are complete.

## macOS and Linux limits in this release

- **Google Drive folder links** work there only with **Read source through the Drive API** turned on. Links that go through Google Drive for Desktop's local folder are Windows-only for now; macOS support is planned.
- **Follow shortcuts** (Windows `.lnk` files) is Windows-only and is hidden elsewhere.
- **AppImage on Ubuntu 24.04 and newer:** install `libfuse2t64` first, or use the `.deb`.

## Install

- **Windows:** `filebridge-setup-2.0.1.exe` (installer) or `filebridge-portable-2.0.1.exe`. Both are signed.
- **macOS:** open the `.dmg` and drag FileBridge to Applications.
- **Linux:** `sudo apt install ./filebridge_2.0.1_amd64.deb`, or make the AppImage executable and run it.
